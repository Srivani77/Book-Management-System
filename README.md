# 📚 Book Management System

## 📌 Project Overview

The Book Management System is a menu-driven application developed using Python. It helps users manage book information through simple operations such as adding, viewing, searching, deleting, and updating book prices.

This project focuses on implementing Python programming concepts, functions, modules, lists, and dictionaries.

## ✨ Features

- **Add Books:** Add new books with details such as name, author, publication year, genre, and price.
- **View Books:** Display all available book records.
- **Search Books:** Search for a book using its name.
- **Delete Books:** Remove a book from the collection.
- **Update Book Price:** Modify the price of an existing book.
- **Menu-Driven Interface:** Choose operations through simple user inputs.

## 🛠️ Technologies Used

- Python
- Lists and Dictionaries
- Functions
- Python Modules

## ▶️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Srivani77/Book-Management-System.git
```

2. Open the project folder in VS Code.

3. Run the following command:

```bash
python bookstore.py
```

4. Select an option from the menu and manage your books.
